# Quiz Editor Unification Diff (`CreateQuiz.jsx` vs `EditQuiz.jsx`)

This document records the exact behavioral differences between the legacy `CreateQuiz.jsx` and `EditQuiz.jsx` components and how the unified `QuizEditor.tsx` + `useQuizEditor.ts` + `quizRepository.ts` architecture reconciles them without data loss.

| Capability | Legacy `CreateQuiz.jsx` | Legacy `EditQuiz.jsx` | Unified `QuizEditor.tsx` |
| --- | --- | --- | --- |
| **Lifecycle & Persistence** | Local React state with `tempId` (`temp-...`) until `Save` (inserts quiz + questions, transitions to `edit-quiz`) or `Save & Exit` (inserts quiz + questions, transitions to `manage-quizzes`). | Loads existing quiz metadata + ordered `questions` from Supabase; mutations execute against DB immediately; `Save` / `Save & Exit` updates `quizzes` metadata. | Parameterized by `quizId?: string`. Draft mode (`!quizId`) manages `tempId` questions locally + persists to `localStorage`; persisted mode (`quizId`) debounces metadata/question autosave (1.5s) and uses `quizRepository.ts`. |
| **Default Theme & Folder** | Queries `themes` with `is_default = true` for initial `themeId`; initializes `folderId` from URL/`activeFolder`. | Reads `theme_id` and `background_image_url` from loaded `quizzes` row. | Draft mode loads default theme + `?folder=` search param (falling back to `quizapp_activeFolder`); persisted mode loads stored `theme_id` and `background_image_url`. |
| **Survey Mode Cleanup (`is_survey`)** | Kept survey flag on insert without clearing existing question answers/points. | On save when `isSurvey` is enabled, clears `points` to `0` and marks all option `is_correct = false` in DB. | Preserves `EditQuiz` survey cleanup on both local state and DB save when `isSurvey` is enabled. |
| **CSV Import & Bulk Edit Feedback** | Contained a `ReferenceError` calling undefined `setSuccess(...)` after CSV import and bulk time/points updates. | Updated DB rows directly and refreshed local question state. | Uses `ToastProvider` (`useToast()`) consistently across both modes; zero undefined state setters. |
| **Unsaved Changes & Recovery** | No draft recovery; prompt on back only via ad-hoc checks. | No navigation blocker on dirty metadata/question edits. | Draft mode saves snapshot to `localStorage` (`quizapp_draft_quiz_new`) with Restore/Discard prompt on mount; dirty state triggers `beforeunload` and React Router `useBlocker`. |
| **Layout & Reordering** | Linear form inside custom gradient `#4a7c7e` header; drag-only reorder. | Same duplicated ~1500-line form; drag-only reorder. | Uses `PageHeader` with token surfaces, three-pane desktop / tabbed mobile workspace (`Questions`, `Editor`, `Preview & Settings`), and both drag-and-drop and accessible `Alt+ArrowUp` / `Alt+ArrowDown` keyboard reordering. |
